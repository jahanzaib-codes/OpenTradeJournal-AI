# 📝 Changelog

All notable changes to **OpenTradeJournal-AI** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-11
### Added
- Multi-broker trade statement ingestion: Interactive Brokers (IBKR CSV), MetaTrader 5 (MT5 Deals), Binance/Bybit JSON fills.
- Quantitative portfolio analytics engine: Win rate, Profit Factor, Sharpe Ratio, Sortino Ratio, Drawdown, Expectancy.
- Cognitive mistake detector: Algorithmic detection for Revenge Trading, FOMO, Overleveraging, Stop-Loss Tampering, and Premature Exits.
- Mental model psychological debiasing advisor and structured executive Markdown reviews.
- FastAPI REST API endpoints with interactive Swagger documentation.
- Standalone interactive CLI terminal for instantaneous trade audits (`python cli.py demo`).
- Containerized Docker and docker-compose deployment orchestration.
- Automated multi-version Python CI workflow and open-source governance policies.
