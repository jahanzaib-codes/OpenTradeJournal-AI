# 🔒 Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We prioritize user data privacy, API token security, and statement integrity. If you identify a potential vulnerability:

1. **Do not disclose publicly:** Please avoid creating public GitHub issues for security reports.
2. **Contact Channel:** Reach out directly via Telegram at [@JanzebBlockdev](https://t.me/JanzebBlockdev) or through verified developer portfolio channels.
3. **Response Timeline:** Reports are acknowledged within 48 hours with remediation patches released within 7 business days.
